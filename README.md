This is a JavaFX application. The application provides a graphical user interface (GUI) to manage data using CRUD operations, supported by a PostgreSQL database via JDBC connectivity

📌 **Features**
* **Database Integration:** Full connectivity with a PostgreSQL database server.
* **CRUD Operations:** Implements functionality for all primary data management tasks.
* **User-Friendly GUI:** Built using JavaFX (version 25).

🛠️ **Technologies**
* **Language:** Java
* **GUI Framework:** JavaFX
* **Database Connectivity:** JDBC
* **Database:** PostgreSQL
